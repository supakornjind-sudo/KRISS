เว็บนับสต็อกสินค้า (ยอดยกมา + วันนี้เพิ่ม − วันนี้เอาออก = รวมยอด) และรายชื่อคนที่ส่งเงินรายสัปดาห์

```
มือถือ / คอมพิวเตอร์
      │  เปิดเว็บ
      ▼
GitHub Pages (index.html)  ── ส่งข้อมูล ──▶  Google Apps Script (Code.gs)
                                                ├─▶ Google Sheet  (รายการของ, บันทึกรายวัน, รายชื่อคน, บันทึกเงินรายสัปดาห์, สรุป, ประวัติ)

```

## 1. ความสามารถ

**หน้า "รายการของ" (สต็อกรายวัน)** — สินค้าแต่ละรายการมี 4 ช่องตัวเลขใหญ่ อ่านง่าย

| ยอดยกมา | + วันนี้เพิ่ม | − วันนี้เอาออก | = รวมยอด |
|---|---|---|---|
| ยอดเมื่อวาน (แก้ได้) | ของเข้าวันนี้ | เอาออกไปใช้วันนี้ | คำนวณให้อัตโนมัติ |

- พิมพ์ตัวเลขได้เลย หรือกดปุ่ม − / + ทีละ 1
- **ขึ้นวันใหม่อัตโนมัติ:** รวมยอดเมื่อวานกลายเป็น "ยอดยกมา" ช่องวันนี้เริ่มที่ 0 และตัวเลขทุกวันถูกเก็บในชีต **บันทึกรายวัน**
- ปุ่ม **ประวัติ** ดูยอดย้อนหลังรายวันของสินค้านั้น
- เพิ่ม/ลบ/แก้ชื่อสินค้า หมวดหมู่ หมายเหตุ, **ใส่รูปสินค้าได้ทุกรายการ** (เก็บใน Google Drive)
- การ์ดสรุป: รวมยอดคงเหลือทุกรายการ, วันนี้เพิ่มรวม, วันนี้เอาออกรวม
- ตัวกรอง "เคลื่อนไหววันนี้" / "ยอดหมด", รายการที่ยอดติดลบจะมีกรอบสีแดง
- กันเพิ่มสินค้าชื่อซ้ำ

**หน้า "รายชื่อคน" (ส่งเงินรายสัปดาห์)**

| ชื่อ | เบอร์โทร | ยอดยกมา | สัปดาห์นี้ส่งแล้ว | ยอดรวมที่ส่งมา |
|---|---|---|---|---|

- ใส่ยอดที่ส่งในสัปดาห์นี้ → ยอดรวมเพิ่มทันที พร้อมป้าย **ส่งแล้ว / ยังไม่ส่ง**
- **ขึ้นสัปดาห์ใหม่ (วันจันทร์) อัตโนมัติ:** ยอดสัปดาห์ก่อนรวมเข้า "ยอดยกมา" และช่องสัปดาห์นี้เริ่มที่ 0 ตัวเลขทุกสัปดาห์เก็บในชีต **บันทึกเงินรายสัปดาห์**
- ปุ่ม **ประวัติ** ดูว่าแต่ละสัปดาห์คนนี้ส่งมาเท่าไร
- ตัวกรอง "ยังไม่ส่งสัปดาห์นี้", เพิ่มหลายชื่อพร้อมเบอร์ทีเดียว
- การ์ดสรุป: เงินสัปดาห์นี้, ส่งแล้วกี่คน, ยอดรวมทั้งหมด
- บนมือถือแสดงเป็นการ์ดทีละคน

**ระบบเสริม**
- ไม่ต้องใส่รหัสผ่าน — เปิดเว็บแล้วใช้ได้เลย
- บันทึกอัตโนมัติ + สถานะ "กำลังบันทึก… / บันทึกแล้ว"
- ใช้หลายคนพร้อมกันได้ ดึงข้อมูลล่าสุดทุก ~20 วินาที และกันการบันทึกทับกัน
- ปุ่ม **สรุป** สร้างข้อความสรุปยอดสินค้าวันนี้ + ใครส่งเงินแล้ว/ยังไม่ส่ง ไว้คัดลอกส่ง LINE
- ชีต "ประวัติการแก้ไข" (ใคร ทำอะไร เมื่อไร), ชีต "สรุป" ที่คำนวณด้วยสูตร
- ปุ่มสำรองข้อมูล + ตั้งงานอัตโนมัติรายวันได้
- ใช้บนมือถือได้ดี รองรับโหมดมืด และมี "โหมดตัวอย่าง" ให้ลองก่อน

## 3. ติดตั้ง ส่วนที่ 1 — Google Sheet + Apps Script

> ใช้เวลาประมาณ 10 นาที ทำบนคอมพิวเตอร์สะดวกที่สุด

### 3.1 สร้าง Google Sheet
1. เปิด <https://sheets.new> (ล็อกอิน Google ก่อน)
2. คลิกชื่อไฟล์มุมซ้ายบน ตั้งชื่อ เช่น `ฐานข้อมูล รายการของ`

### 3.2 วางโค้ด
1. ในชีต ไปที่เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดเดิม `function myFunction() {…}` ทิ้งให้หมด
3. เปิดไฟล์ `apps-script/Code.gs` → คัดลอกทั้งหมด → วางแทน
4. ตั้งชื่อโปรเจกต์ เช่น `รายการของ API` แล้วกด **💾 บันทึก** (`Ctrl + S`)

### 3.3 ตั้งเขตเวลา (สำคัญ — ใช้ตัดวัน/สัปดาห์)
1. แถบซ้ายกด **⚙️ การตั้งค่าโปรเจ็กต์ (Project Settings)**
2. ช่อง **เขตเวลา (Time zone)** เลือก `(GMT+07:00) Bangkok`

### 3.4 รัน setup ครั้งแรก (ให้สิทธิ์)
1. กลับไปหน้า **<> ตัวแก้ไข (Editor)**
2. แถบด้านบน เลือกฟังก์ชัน **`setup`** → กด **▶ เรียกใช้ (Run)**
3. **ตรวจสอบสิทธิ์** → เลือกบัญชี Google
4. ถ้าขึ้น **"Google ยังไม่ได้ยืนยันแอปนี้"** → **ขั้นสูง (Advanced)** → **ไปที่ รายการของ API (ไม่ปลอดภัย)**
   *(ปกติสำหรับสคริปต์ที่เขียนเอง — สคริปต์นี้ใช้แค่ชีตนี้และโฟลเดอร์ที่มันสร้าง)*
5. กด **อนุญาต (Allow)**
6. ใน **บันทึกการดำเนินการ** ต้องเห็น `✅ ติดตั้งเสร็จแล้ว (วันที่ของระบบ: …)` — ตรวจว่าวันที่ถูกต้อง
7. ในชีตจะมีแท็บ `รายการของ`, `บันทึกรายวัน`, `รายชื่อคน`, `บันทึกเงินรายสัปดาห์`, `สรุป`, `ประวัติการแก้ไข`
8. (แนะนำ) เลือกฟังก์ชัน **`setupDailyJobs`** → ▶ เรียกใช้ 1 ครั้ง = ทุกคืนเวลาประมาณเที่ยงคืนระบบจะยกยอดให้เองแม้ไม่มีใครเปิดเว็บ และตีสองสำรองข้อมูลอัตโนมัติ

### 3.5 Deploy เป็น Web App
1. มุมขวาบน **การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. กด ⚙️ ข้าง "เลือกประเภท" → **เว็บแอป (Web app)**
3. ตั้งค่า:
   - ดำเนินการในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)** ← ต้องเป็นอันนี้
4. กด **ทำให้ใช้งานได้ (Deploy)** → **คัดลอก URL ของเว็บแอป** (`https://script.google.com/macros/s/AKfy…/exec`)
5. ทดสอบ: วางลิงก์ในเบราว์เซอร์ ต้องเห็น `{"ok":true, … "API พร้อมใช้งาน" …}`

## 4. ติดตั้ง ส่วนที่ 2 — GitHub Pages

### 4.1 สร้าง repository
1. ล็อกอิน <https://github.com> → มุมขวาบน **+ → New repository**
2. Repository name: เช่น `shoplist` (ภาษาอังกฤษ ไม่มีเว้นวรรค)
3. เลือก **Public** → **Create repository**

### 4.2 ใส่ลิงก์ Web App ลงในหน้าเว็บ (แนะนำ)
ทำแล้วทุกคนเปิดเว็บใช้ได้ทันที ไม่ต้องกรอกอะไรเลย
1. เปิด `index.html` ด้วยโปรแกรมแก้ข้อความ (Notepad / VS Code) — หรือแก้หลังอัปโหลดใน GitHub ด้วยปุ่มดินสอ ✏️
2. กด `Ctrl + F` หา `var DEFAULT_API_URL = '';`
3. ใส่ลิงก์จากข้อ 3.5 เช่น
   `var DEFAULT_API_URL = 'https://script.google.com/macros/s/AKfy…/exec';`
4. บันทึกไฟล์

> ถ้าไม่ใส่ตรงนี้ ครั้งแรกที่เปิดเว็บ แต่ละเครื่องจะต้องวางลิงก์ Web App เอง 1 ครั้ง (หรือส่ง "ลิงก์เชิญ" จากเมนู ⋯ ให้)

### 4.3 อัปโหลดไฟล์
1. ในหน้า repository กด **uploading an existing file**
2. ลาก `index.html`, `README.md` และโฟลเดอร์ `apps-script` ลงไป
3. กด **Commit changes**

### 4.4 เปิด GitHub Pages
1. **Settings → Pages**
2. **Source:** Deploy from a branch · **Branch:** `main` / `(root)` → **Save**
3. รอ 1–3 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/shoplist/`
4. เปิดลิงก์ → ใช้งานได้เลย (ส่งลิงก์นี้ให้คนในทีมได้)
5. **เพิ่มลงหน้าจอโฮมมือถือ:** iPhone (Safari) ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม / Android (Chrome) ⋮ → เพิ่มลงในหน้าจอหลัก

## 5. อัปเดตจากเวอร์ชันก่อน

ถ้าเคยติดตั้งเวอร์ชันแรก (ที่มีราคา/รหัสผ่าน/ช่องหลังชื่อแบบกำหนดเอง):

1. **Apps Script:** ลบโค้ดเก่า → วาง `Code.gs` ใหม่ → บันทึก
2. ตั้งเขตเวลาตามข้อ 3.3 แล้วรัน `setup` อีกครั้ง
3. **Deploy เวอร์ชันใหม่:** การทำให้ใช้งานได้ → **จัดการการทำให้ใช้งานได้** → ✏️ → เวอร์ชัน: **เวอร์ชันใหม่** → ทำให้ใช้งานได้ (ลิงก์เดิมใช้ต่อได้)
4. **GitHub:** แทนที่ `index.html` ด้วยไฟล์ใหม่ (อย่าลืมใส่ลิงก์ตามข้อ 4.2)
5. ระบบจะ **แปลงข้อมูลเดิมให้อัตโนมัติ**
   - สินค้า: "จำนวน" เดิม → **ยอดยกมา** (ราคาเดิมถูกเก็บในหมายเหตุ)
   - รายชื่อ: ช่องที่มีคำว่า "เบอร์/โทร" → **เบอร์โทร**, ช่องตัวเลขที่มีคำว่า "เงิน/โอน" → **ยอดยกมา**
   - ชีตเดิมถูกเก็บสำรองไว้เป็น `รายการของ (แบบเดิม)` และ `รายชื่อคน (แบบเดิม)` — ลบทิ้งได้เมื่อตรวจแล้ว
6. (ไม่บังคับ) ลบพร็อพเพอร์ตี้ `APP_PASSWORD` และชีต `ตั้งค่าช่อง` ที่ไม่ใช้แล้ว

## 6. วิธีใช้งาน

### 6.1 หน้า "รายการของ"

| อยากทำอะไร | ทำอย่างไร |
|---|---|
| เพิ่มสินค้าใหม่ | กรอก **ชื่อ** และ **ยอดตั้งต้น** (จำนวนที่มีอยู่แล้ว) → **+ เพิ่ม** |
| วันนี้ได้ของเข้ามา | พิมพ์จำนวนในช่อง **+ วันนี้เพิ่ม** (หรือกด + ทีละ 1) |
| วันนี้เอาของออกไปใช้ | พิมพ์จำนวนในช่อง **− วันนี้เอาออก** |
| เข้า/ออกหลายรอบในวันเดียว | ช่องวันนี้คือ **ยอดรวมของทั้งวัน** เช่น เช้าเพิ่ม 10 บ่ายเพิ่มอีก 5 → แก้เป็น 15 |
| นับสต็อกจริงแล้วไม่ตรง | แก้ช่อง **ยอดยกมา** |
| ดูย้อนหลัง | ปุ่ม **ประวัติ** |
| ใส่/เปลี่ยนรูป | กดกรอบรูปของสินค้า (ถ่ายรูปจากมือถือได้) |
| ลบรูป / ลบสินค้า | ปุ่ม **ลบรูป** / **ลบสินค้า** (กด **เลิกทำ** ได้ 6 วินาที) |

> เทคนิค: คลิกช่องตัวเลขแล้วตัวเลขจะถูกเลือกทั้งช่อง พิมพ์ทับได้ทันที แล้วกด `Enter`

### 6.2 หน้า "รายชื่อคน"

| อยากทำอะไร | ทำอย่างไร |
|---|---|
| เพิ่มคน | กรอกชื่อ เบอร์ (และยอดที่เคยส่งมาแล้ว ถ้ามี) → **+ เพิ่มชื่อ** |
| เพิ่มหลายคน | **เพิ่มหลายชื่อพร้อมกัน** → วางบรรทัดละคน เช่น `สมชาย 081-234-5678` |
| มีคนโอนเงินมาสัปดาห์นี้ | พิมพ์ยอดในช่อง **สัปดาห์นี้ส่งแล้ว** → ยอดรวมเพิ่ม + ขึ้นป้าย "ส่งแล้ว" |
| ส่งหลายครั้งในสัปดาห์ | ใส่ **ยอดรวมของสัปดาห์** เช่น 200 + 300 → ใส่ 500 |
| ดูใครยังไม่ส่ง | ตัวกรอง **ยังไม่ส่งสัปดาห์นี้** |
| ดูประวัติรายสัปดาห์ | ปุ่ม **ประวัติ** |
| แก้ชื่อ/เบอร์/ยอดยกมา | คลิกในตารางแล้วพิมพ์ |
| ลบคน | ปุ่ม **ลบ** (เลิกทำได้) |

สัปดาห์นับ **จันทร์–อาทิตย์** (เปลี่ยนได้ที่ `WEEK_START` ใน `Code.gs`)

### 6.3 ปุ่มด้านบน
- **สรุป** — ข้อความสรุปยอดสินค้าวันนี้ + ใครส่งเงินแล้ว/ยังไม่ส่ง → **คัดลอก** → วางใน LINE
- **↻** — โหลดข้อมูลล่าสุด
- **⋯** — เปิด Google Sheet, เปิดโฟลเดอร์ Drive, สำรองข้อมูลตอนนี้, คัดลอกลิงก์เชิญ, ตั้งค่าการเชื่อมต่อ

## 7. ข้อมูลเก็บอยู่ที่ไหน

| แท็บใน Google Sheet | เนื้อหา |
|---|---|
| `รายการของ` | ID, รูป, ชื่อสินค้า, หมวดหมู่, **ยอดยกมา, วันนี้เพิ่ม, วันนี้เอาออก, รวมยอด (สูตร)**, วันที่ของช่องวันนี้, หมายเหตุ, (ซ่อน: ข้อมูลรูป), อัปเดตล่าสุด |
| `บันทึกรายวัน` | วันที่, Item ID, ชื่อสินค้า, ยอดยกมา, เพิ่ม, เอาออก, คงเหลือ — 1 แถวต่อ 1 สินค้าต่อ 1 วัน (เฉพาะวันที่มีเคลื่อนไหว) |
| `รายชื่อคน` | ID, ชื่อ, เบอร์โทร, **ยอดยกมา, สัปดาห์นี้ส่งแล้ว, ยอดรวมที่ส่งมา (สูตร)**, สัปดาห์ที่เริ่ม, อัปเดตล่าสุด |
| `บันทึกเงินรายสัปดาห์` | สัปดาห์ที่เริ่ม, Person ID, ชื่อ, ยอดยกมา, ส่งสัปดาห์นี้, ยอดรวม — 1 แถวต่อ 1 คนต่อ 1 สัปดาห์ (เฉพาะสัปดาห์ที่ส่ง) |
| `สรุป` | จำนวนสินค้า, รวมยอด, วันนี้เพิ่ม/เอาออก, จำนวนคน, เงินสัปดาห์นี้, ยอดเงินรวม |
| `ประวัติการแก้ไข` | เวลา, ชื่อผู้ใช้, ส่วน, รายละเอียด (ล่าสุด 1,000 แถว) |

**Google Drive** → โฟลเดอร์ `รายการของ & รายชื่อ (ข้อมูลระบบ)` มี `รูปสินค้า/` และ `สำรองข้อมูล/`

**แก้ในชีตตรง ๆ ได้ไหม?** ได้ แต่
- อย่าแก้/ลบคอลัมน์ ID และคอลัมน์วันที่/สัปดาห์ที่เริ่ม
- หลังแก้ในชีต ให้กด ↻ ในหน้าเว็บก่อนแก้ต่อ
- ทำ **Pivot table / กราฟ** จากชีต `บันทึกรายวัน` เพื่อดูยอดใช้รายเดือนได้

## 8. การแก้ไข/อัปเดตระบบภายหลัง

- **แก้หน้าเว็บ** → แก้ `index.html` ใน GitHub (✏️ → Commit) รอ 1–2 นาที
- **แก้ `Code.gs`** → บันทึก แล้ว **Deploy เวอร์ชันใหม่** (จัดการการทำให้ใช้งานได้ → ✏️ → เวอร์ชันใหม่) ลิงก์เดิมจะใช้ต่อได้
  *(ถ้ากด "การทำให้ใช้งานได้รายการใหม่" จะได้ลิงก์ใหม่ ต้องแก้ `DEFAULT_API_URL` ด้วย)*
- **ค่าที่ปรับได้** ในส่วน `CONFIG` ของ `Code.gs`: ชื่อแท็บ, ชื่อโฟลเดอร์, `WEEK_START` (วันเริ่มสัปดาห์)

## 9. ความปลอดภัย

- **ไม่มีรหัสผ่าน:** ใครมีลิงก์เว็บ (หรือลิงก์ Web App) **ดูและแก้ไขข้อมูลได้** — ส่งลิงก์เฉพาะคนที่ไว้ใจ
- ถ้าลิงก์หลุด: Apps Script → จัดการการทำให้ใช้งานได้ → **เก็บถาวร (Archive)** แล้ว Deploy รายการใหม่ (ได้ลิงก์ใหม่) → แก้ `DEFAULT_API_URL`
- ไฟล์ Google Sheet ยังเป็นของคุณคนเดียว (ไม่ได้ถูกแชร์) และมีชีต "ประวัติการแก้ไข" + ปุ่มสำรองข้อมูล
- **รูปสินค้าตั้งเป็น "ทุกคนที่มีลิงก์ดูได้"** เพื่อให้แสดงบนเว็บ อย่าอัปรูปที่เป็นความลับ
- ข้อความที่ขึ้นต้นด้วย `= + - @` จะถูกกันไม่ให้กลายเป็นสูตร

## 10. แก้ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| ขึ้นหน้า "เชื่อมต่อ Google Sheet" ทุกครั้ง | ยังไม่ได้ใส่ `DEFAULT_API_URL` (ข้อ 4.2) หรือเบราว์เซอร์ลบข้อมูลเว็บ |
| "ลิงก์ Web App ไม่ถูกต้อง…" | Deploy ให้ **ผู้ที่มีสิทธิ์เข้าถึง = ทุกคน (Anyone)** และใช้ลิงก์ลงท้าย `/exec` |
| "เชื่อมต่อไม่ได้" | ตรวจอินเทอร์เน็ต / เปิดลิงก์ `/exec` ดูว่าขึ้น `"ok":true` |
| วันไม่ตัด/ตัดผิดเวลา | ตั้งเขตเวลา Bangkok (ข้อ 3.3) แล้ว Deploy เวอร์ชันใหม่ |
| ช่องวันนี้ไม่รีเซ็ต | ระบบรีเซ็ตเมื่อมีคนเปิดเว็บในวันใหม่ หรือรัน `setupDailyJobs` ให้ทำเองทุกคืน |
| แก้โค้ดแล้วไม่เปลี่ยน | ยังไม่ได้ Deploy **เวอร์ชันใหม่** |
| รูปไม่ขึ้น | รอสักครู่แล้วกด ↻ / ตรวจว่ารูปยังอยู่ในโฟลเดอร์ `รูปสินค้า` |
| เลือกรูปจาก iPhone แล้ว "เปิดรูปนี้ไม่ได้" | ตั้งค่า iPhone: กล้อง → รูปแบบ → **เข้ากันได้มากที่สุด** |
| "มีคนแก้ไขข้อมูลพร้อมกัน…" | ระบบโหลดข้อมูลล่าสุดแล้ว ให้ทำรายการสุดท้ายซ้ำ |
| เว็บ GitHub ขึ้น 404 | รอ 2–3 นาที, ไฟล์ต้องชื่อ `index.html` อยู่ชั้นนอกสุด |
| เห็นหน้าเว็บเวอร์ชันเก่า | `Ctrl + Shift + R` |

## 11. ระบบที่แนะนำให้เพิ่ม

1. **แจ้งเตือนสินค้าใกล้หมด** — ตั้งจุดสั่งซื้อต่อสินค้า (เช่น ต่ำกว่า 20) แล้วขึ้นสีส้ม + รวมไว้ในข้อความสรุป
2. **ยอดที่ต้องส่งต่อสัปดาห์** — ตั้งยอดเป้าหมาย (เช่น 500 บาท/สัปดาห์) แล้วแสดง "ค้างอีกเท่าไร" ต่อคน
3. **QR พร้อมเพย์** ตามยอดที่ต้องส่งของแต่ละคน
4. **แนบสลิปโอนเงิน** ต่อคนต่อสัปดาห์ เก็บลง Drive
5. **บันทึกทีละรายการพร้อมเวลา** (เช่น 09:10 เพิ่ม 10, 14:30 เพิ่ม 5) แทนการใส่ยอดรวมของวัน
6. **รายงานรายเดือน/กราฟ** การใช้สินค้าและยอดเงิน
7. **ผู้ใช้หลายระดับ** — บางคนดูได้อย่างเดียว บางคนแก้ไขได้ (ล็อกอินด้วย Google)
8. **แจ้งเตือนเข้า LINE กลุ่ม** ผ่าน LINE Messaging API (LINE Notify ปิดบริการไปแล้ว)
9. **สแกนบาร์โค้ด** ด้วยกล้องมือถือเพื่อหาสินค้าเร็วขึ้น
10. **ส่งออก PDF** ใบสรุปประจำวัน/สัปดาห์
