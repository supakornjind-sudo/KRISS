# รายการของ & รายชื่อ

เว็บจดรายการของพร้อมรวมยอดอัตโนมัติ และหน้ารายชื่อคนที่เพิ่มช่องหลังชื่อได้ (เช่น "ส่งเงินแล้ว")
ตัวเว็บอยู่บน **GitHub Pages** (ฟรี) ส่วนข้อมูลเก็บใน **Google Sheet** และรูปเก็บใน **Google Drive** ของคุณเอง

```
มือถือ / คอมพิวเตอร์
      │  เปิดเว็บ
      ▼
GitHub Pages (index.html)  ──ส่งข้อมูล + รหัสผ่าน──▶  Google Apps Script (Code.gs)
                                                         ├─▶ Google Sheet  (รายการของ, รายชื่อคน, สรุป, ประวัติ)
                                                         └─▶ Google Drive  (รูปสินค้า, ไฟล์สำรอง)
```

## 1. ความสามารถ

**หน้า "รายการของ"**
- เพิ่ม / ลบ / แก้ไขชื่อสินค้า ราคาต่อหน่วย จำนวน หมวดหมู่ และหมายเหตุ
- **ใส่รูปสินค้าได้ทุกช่อง** (เลือกจากเครื่องหรือถ่ายด้วยมือถือ) ระบบย่อรูปให้อัตโนมัติแล้วเก็บใน Google Drive
- **รวมยอดอัตโนมัติ** — ติ๊กออก = เอาออกจากยอดรวมทันที (ติ๊กกลับได้) / กด "ลบ" = ลบถาวร (กด "เลิกทำ" ได้ 6 วินาที)
- ปุ่ม + / − ปรับจำนวน, ค้นหา, กรอง (ทั้งหมด / นับในยอด / เอาออก), เรียงลำดับ
- แสดง **ยอดหารต่อคน** จากจำนวนคนในหน้ารายชื่อ

**หน้า "รายชื่อคน"**
- เพิ่ม / ลบ / แก้ไขชื่อ, วางรายชื่อทีละหลายชื่อ, เตือนชื่อซ้ำ
- **เพิ่ม / ลบ / เปลี่ยนชื่อ / ย้ายตำแหน่ง ช่องหลังชื่อ** ได้ 3 ชนิด
  - ช่องติ๊ก (เช่น ส่งเงินแล้ว, ได้รับของแล้ว)
  - ข้อความ (เช่น เบอร์โทร, หมายเหตุ)
  - ตัวเลข (เช่น ยอดที่โอน — ระบบรวมยอดให้)
- ปุ่ม "ติ๊กทั้งหมด / ล้าง" ต่อช่อง, ตัวกรอง "ใครยังไม่ส่งเงิน", แถบความคืบหน้า
- คำนวณ **เก็บเงินได้แล้ว / ยังค้าง** (จากช่องติ๊กที่ชื่อมีคำว่า เงิน / จ่าย / โอน / ชำระ)

**ระบบเสริมที่ใส่ไว้ให้แล้ว**
- บันทึกอัตโนมัติ + สถานะ "กำลังบันทึก… / บันทึกแล้ว"
- ใช้หลายคนพร้อมกันได้ — ดึงข้อมูลล่าสุดทุก ~20 วินาที และกันการบันทึกทับกัน
- ปุ่ม **สรุป** สร้างข้อความสรุปยอด + ใครจ่ายแล้ว/ยังไม่จ่าย ไว้คัดลอกส่ง LINE
- **ลิงก์เชิญเพื่อน** เปิดแล้วเข้าใช้ได้ทันที ไม่ต้องกรอกอะไร
- ชีต "ประวัติการแก้ไข" (ใคร ทำอะไร เมื่อไร) และชีต "สรุป" ที่คำนวณด้วยสูตร
- ปุ่มสำรองข้อมูล และตั้งสำรองอัตโนมัติรายวันได้
- ใช้บนมือถือได้ดี, รองรับโหมดมืด, มี "โหมดตัวอย่าง" ให้ลองเล่นก่อนติดตั้ง

## 3. ติดตั้ง ส่วนที่ 1 — Google Sheet + Apps Script

> ใช้เวลาประมาณ 10 นาที ทำบนคอมพิวเตอร์จะสะดวกที่สุด

### 3.1 สร้าง Google Sheet
1. เปิด <https://sheets.new> (ล็อกอิน Google ก่อน)
2. คลิกชื่อไฟล์มุมซ้ายบน ตั้งชื่อ เช่น `ฐานข้อมูล รายการของ`

### 3.2 วางโค้ด
1. ในชีต ไปที่เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. จะเห็นไฟล์ `Code.gs` ที่มีโค้ด `function myFunction() {…}` → **ลบทิ้งให้หมด**
3. เปิดไฟล์ `apps-script/Code.gs` จากโปรเจกต์นี้ → คัดลอกทั้งหมด → วางแทน
4. ตั้งชื่อโปรเจกต์ (มุมซ้ายบน) เช่น `รายการของ API` แล้วกด **💾 บันทึก** (หรือ `Ctrl + S`)

### 3.3 ตั้งรหัสผ่าน (สำคัญ)
1. แถบซ้ายกด **⚙️ การตั้งค่าโปรเจ็กต์ (Project Settings)**
2. (แนะนำ) ติ๊ก **แสดงไฟล์ Manifest…** ไม่ต้องก็ได้ — ให้ดูช่อง **เขตเวลา (Time zone)** เลือก `(GMT+07:00) Bangkok`
3. เลื่อนลงล่างสุด **พร็อพเพอร์ตี้ของสคริปต์ (Script Properties) → เพิ่มพร็อพเพอร์ตี้ของสคริปต์**
   - พร็อพเพอร์ตี้: `APP_PASSWORD`
   - ค่า: รหัสผ่านที่ต้องการ **อย่างน้อย 6 ตัว** (แนะนำให้ยาว ๆ เช่น `ทริปเชียงใหม่2026!`)
4. กด **บันทึกพร็อพเพอร์ตี้ของสคริปต์**

> ⚠️ อย่าไปใส่รหัสจริงในไฟล์ `Code.gs` ที่อยู่บน GitHub เพราะ repository แบบ Public ทุกคนเปิดอ่านได้

### 3.4 รัน setup ครั้งแรก (ให้สิทธิ์)
1. กลับไปหน้า **<> ตัวแก้ไข (Editor)**
2. แถบด้านบน เลือกฟังก์ชัน **`setup`** แล้วกด **▶ เรียกใช้ (Run)**
3. จะมีหน้าต่าง **ต้องมีการให้สิทธิ์** → **ตรวจสอบสิทธิ์** → เลือกบัญชี Google ของคุณ
4. ถ้าขึ้น **"Google ยังไม่ได้ยืนยันแอปนี้"** → กด **ขั้นสูง (Advanced)** → **ไปที่ รายการของ API (ไม่ปลอดภัย)**
   *(ปกติสำหรับสคริปต์ที่เราเขียนเอง — สคริปต์นี้เข้าถึงเฉพาะชีตนี้และโฟลเดอร์ที่มันสร้างเท่านั้น)*
5. กด **อนุญาต (Allow)**
6. ดู **บันทึกการดำเนินการ (Execution log)** ด้านล่าง ต้องเห็น `🔒 ตั้งรหัสผ่านแล้ว` และ `✅ ติดตั้งเสร็จแล้ว`
7. กลับไปที่ Google Sheet จะมีแท็บ `รายการของ`, `รายชื่อคน`, `ตั้งค่าช่อง`, `สรุป`, `ประวัติการแก้ไข`
   และใน Google Drive จะมีโฟลเดอร์ `รายการของ & รายชื่อ (ข้อมูลระบบ)` ที่มีโฟลเดอร์ `รูปสินค้า` และ `สำรองข้อมูล`

### 3.5 Deploy เป็น Web App
1. มุมขวาบน กด **การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. กดรูปเฟือง ⚙️ ข้าง "เลือกประเภท" → เลือก **เว็บแอป (Web app)**
3. ตั้งค่า:
   - คำอธิบาย: `v1`
   - ดำเนินการในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)** ← ต้องเป็นอันนี้ ไม่ใช่ "ทุกคนที่มีบัญชี Google"
4. กด **ทำให้ใช้งานได้ (Deploy)**
5. **คัดลอก URL ของเว็บแอป** (หน้าตาแบบ `https://script.google.com/macros/s/AKfy…/exec`) เก็บไว้
6. ทดสอบ: วางลิงก์นั้นในเบราว์เซอร์ ต้องเห็นข้อความ `{"ok":true, … "API พร้อมใช้งาน" …}`

> "ทุกคน" ในที่นี้หมายถึงทุกคนเรียก API ได้ **แต่ต้องมีรหัสผ่าน** ถึงจะอ่าน/แก้ข้อมูลได้ ส่วนไฟล์ Google Sheet ยังเป็นของคุณคนเดียว (ไม่ถูกแชร์)

## 4. ติดตั้ง ส่วนที่ 2 — GitHub Pages

### 4.1 สร้าง repository
1. สมัคร / ล็อกอิน <https://github.com>
2. มุมขวาบนกด **+ → New repository**
3. Repository name: เช่น `shoplist` (ใช้ภาษาอังกฤษ ไม่มีเว้นวรรค)
4. เลือก **Public** (GitHub Pages แบบฟรีต้องเป็น Public)
5. กด **Create repository**

### 4.2 อัปโหลดไฟล์
1. ในหน้า repository ใหม่ กดลิงก์ **uploading an existing file**
2. แตกไฟล์ zip ที่ได้ แล้ว **ลากไฟล์ `index.html`, `README.md` และโฟลเดอร์ `apps-script`** ลงในหน้าเว็บ
3. เลื่อนลงล่าง กด **Commit changes**

> ทางเลือกสำหรับคนใช้ Git:
> ```bash
> git clone https://github.com/<ชื่อผู้ใช้>/shoplist.git
> cd shoplist
> # คัดลอกไฟล์ทั้งหมดมาไว้ในโฟลเดอร์นี้
> git add . && git commit -m "เริ่มต้นระบบรายการของ" && git push
> ```

### 4.3 เปิด GitHub Pages
1. ในหน้า repository กด **Settings** (แท็บบนสุด)
2. เมนูซ้ายกด **Pages**
3. หัวข้อ **Build and deployment → Source** เลือก **Deploy from a branch**
4. **Branch** เลือก `main` และโฟลเดอร์ `/ (root)` → กด **Save**
5. รอ 1–3 นาที แล้วรีเฟรช จะเห็นลิงก์ **Your site is live at**
   `https://<ชื่อผู้ใช้>.github.io/shoplist/`

### 4.4 (ไม่บังคับ) ฝังลิงก์ Web App ไว้ในเว็บ
ถ้าอยากให้คนอื่นกรอกแค่รหัสผ่าน ไม่ต้องกรอกลิงก์ยาว ๆ:
1. ใน GitHub เปิดไฟล์ `index.html` → กดรูปดินสอ ✏️ (Edit)
2. กด `Ctrl + F` หา `var DEFAULT_API_URL = '';`
3. ใส่ลิงก์ในเครื่องหมาย `'…'` เช่น `var DEFAULT_API_URL = 'https://script.google.com/macros/s/AKfy…/exec';`
4. กด **Commit changes** แล้วรอ 1–2 นาที

*(ลิงก์นี้เปิดเผยได้ เพราะถ้าไม่มีรหัสผ่านก็ใช้งานไม่ได้ — **ห้ามใส่รหัสผ่านลงในไฟล์นี้**)*

## 5. ติดตั้ง ส่วนที่ 3 — เชื่อมต่อครั้งแรกและชวนเพื่อน

1. เปิด `https://<ชื่อผู้ใช้>.github.io/shoplist/`
2. หน้า **เชื่อมต่อ Google Sheet** จะขึ้นมา
   - ลิงก์ Web App: วางลิงก์จากข้อ 3.5
   - รหัสผ่าน: รหัสจากข้อ 3.3
   - ชื่อของคุณ: ชื่อที่จะแสดงในชีตประวัติ (ไม่บังคับ)
3. กด **เชื่อมต่อ** → เข้าใช้งานได้ ระบบจำค่าไว้ในเครื่องนั้น ครั้งหน้าไม่ต้องกรอกใหม่
4. **ชวนเพื่อน:** เมนู **⋯ → คัดลอกลิงก์เชิญเพื่อน** → ส่งลิงก์ให้เพื่อนใน LINE เพื่อนกดแล้วใช้ได้เลย
   (ลิงก์นี้มีรหัสผ่านอยู่ข้างใน — ส่งเฉพาะคนที่ไว้ใจ)
5. **เพิ่มลงหน้าจอโฮมมือถือ** ให้เปิดเหมือนแอป
   - iPhone (Safari): ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
   - Android (Chrome): เมนู ⋮ → **เพิ่มลงในหน้าจอหลัก**

> อยากลองก่อนติดตั้ง? กด **ลองโหมดตัวอย่าง** ในหน้าเชื่อมต่อ (ข้อมูลจะหายเมื่อปิดหน้า)

## 6. วิธีใช้งาน

### 6.1 หน้า "รายการของ"

| อยากทำอะไร | ทำอย่างไร |
|---|---|
| เพิ่มสินค้า | กรอก ชื่อ / ราคาต่อหน่วย / จำนวน / หมวดหมู่ ในกล่อง "เพิ่มสินค้า" → กด **+ เพิ่ม** หรือ `Enter` |
| ใส่รูปตอนเพิ่ม | กดกรอบ **ใส่รูป** ในกล่องเพิ่มสินค้า ก่อนกดเพิ่ม |
| ใส่/เปลี่ยนรูปสินค้าที่มีอยู่ | กดที่กรอบรูปของสินค้านั้น → เลือกรูป / ถ่ายรูป |
| ลบรูป | กดปุ่ม **ลบรูป** (รูปย้ายไปถังขยะใน Drive กู้คืนได้ 30 วัน) |
| แก้ชื่อ / ราคา / จำนวน / หมายเหตุ | คลิกที่ข้อความแล้วพิมพ์ ระบบบันทึกเอง |
| **เอาออกจากยอดรวม** | เอาติ๊ก ✓ หน้าสินค้าออก → รายการจางลง ยอดรวมลดทันที |
| เอากลับเข้ายอด | ติ๊ก ✓ กลับ |
| **ลบสินค้า** | กด **ลบ** → ถ้ากดผิด กด **เลิกทำ** ที่แถบด้านล่างภายใน 6 วินาที |
| จัดการทีละหลายรายการ | ปุ่มท้ายหน้า: นับทุกรายการ / เอาออกทุกรายการ / ลบรายการที่เอาออกทั้งหมด |

การ์ดด้านบนแสดง: **ยอดรวม** (เฉพาะที่ติ๊ก), **จำนวนชิ้น**, ยอดที่เอาออก และ **หารต่อคน**

### 6.2 หน้า "รายชื่อคน"

| อยากทำอะไร | ทำอย่างไร |
|---|---|
| เพิ่มชื่อ | พิมพ์ชื่อ → `Enter` |
| เพิ่มหลายชื่อ | กด **เพิ่มหลายชื่อ** → วางรายชื่อบรรทัดละชื่อ (ตัวเลขนำหน้า เช่น `1.` จะถูกตัดให้เอง) |
| แก้ชื่อ | คลิกชื่อในตารางแล้วพิมพ์ |
| ลบชื่อ | กด **ลบ** ท้ายแถว (เลิกทำได้) |
| **เพิ่มช่องหลังชื่อ** | กล่อง "ช่องหลังชื่อ" → พิมพ์ชื่อช่อง → เลือกชนิด → **+ เพิ่มช่อง** หรือกดช่องแนะนำ |
| เปลี่ยนชื่อช่อง | พิมพ์ทับชื่อในป้ายช่อง |
| เปลี่ยนชนิดช่อง | เลือกในดรอปดาวน์ของป้ายช่อง |
| ย้ายช่อง | กด ‹ หรือ › |
| **ลบช่อง** | กด × (ข้อมูลช่องนั้นของทุกคนจะถูกลบ) |
| ติ๊กให้ทุกคน / ล้าง | ลิงก์ใต้หัวคอลัมน์ช่องติ๊ก |
| ดูว่าใครยังไม่ส่งเงิน | ตัวกรอง **แสดง: ยังไม่ ส่งเงินแล้ว** |

> ช่องติ๊กที่ชื่อมีคำว่า **เงิน / จ่าย / โอน / ชำระ** (ช่องแรกที่เจอ) จะถูกใช้คำนวณ "เก็บแล้ว / ค้าง" และชื่อคนที่ติ๊กแล้วจะเป็นสีเขียว

### 6.3 ปุ่มด้านบน
- **สรุป** — ข้อความสรุปรายการ ยอดรวม ยอดต่อคน และรายชื่อคนที่จ่าย/ยังไม่จ่าย → กด **คัดลอก** → วางใน LINE
- **↻** — โหลดข้อมูลล่าสุด (ปกติระบบดึงให้เองทุก ~20 วินาที)
- **⋯** — เปิด Google Sheet, เปิดโฟลเดอร์ Drive, สำรองข้อมูลตอนนี้, คัดลอกลิงก์เชิญ, ตั้งค่าการเชื่อมต่อ

### 6.4 สถานะการบันทึก (ใต้ชื่อเว็บ)
- 🟢 **บันทึกแล้ว 14:32** — ข้อมูลอยู่ใน Google Sheet แล้ว
- 🟠 **กำลังบันทึก…** — รอสักครู่ก่อนปิดหน้า (ถ้าปิด เบราว์เซอร์จะเตือน)
- 🔴 **บันทึกไม่สำเร็จ** — ระบบจะลองใหม่ทุก 5 วินาที ตรวจอินเทอร์เน็ต

## 8. การแก้ไข/อัปเดตระบบภายหลัง

**แก้หน้าเว็บ (`index.html`)** → แก้ใน GitHub (✏️ → Commit) รอ 1–2 นาที แล้วรีเฟรชเว็บ

**แก้โค้ด Google (`Code.gs`)** → วางโค้ดใหม่ใน Apps Script → บันทึก แล้ว **ต้อง Deploy เวอร์ชันใหม่**:
1. **การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ (Manage deployments)**
2. เลือกรายการเดิม → กดรูปดินสอ ✏️
3. เวอร์ชัน: **เวอร์ชันใหม่ (New version)** → **ทำให้ใช้งานได้**

> ใช้วิธีนี้ลิงก์ `/exec` จะ **เหมือนเดิม** ถ้าไปกด "การทำให้ใช้งานได้รายการใหม่" จะได้ลิงก์ใหม่ ต้องเชื่อมต่อใหม่ทุกเครื่อง

**เปลี่ยนรหัสผ่าน** → แก้ค่า `APP_PASSWORD` ในพร็อพเพอร์ตี้ของสคริปต์ (มีผลทันที ไม่ต้อง Deploy ใหม่) → ทุกเครื่องจะถูกขอรหัสใหม่

**ปรับค่าอื่น ๆ** ที่ส่วน `CONFIG` ด้านบนของ `Code.gs` เช่น ชื่อแท็บ ชื่อโฟลเดอร์ ช่องเริ่มต้น

## 9. ความปลอดภัย

- ข้อมูลทั้งหมดอยู่ใน Google Drive ของคุณ GitHub เก็บแค่หน้าเว็บ (ไม่มีข้อมูล)
- ทุกคำสั่งต้องมีรหัสผ่านถูกต้อง ใส่รหัสผิดระบบจะหน่วงเวลาเพื่อกันการเดา
- รหัสผ่านถูกจำไว้ใน **เบราว์เซอร์ของแต่ละเครื่อง** — ถ้าใช้เครื่องสาธารณะ ให้ล้างข้อมูลเว็บไซต์หลังใช้
- **รูปสินค้าตั้งเป็น "ทุกคนที่มีลิงก์ดูได้"** เพื่อให้แสดงบนเว็บได้ อย่าอัปรูปที่เป็นความลับ
  (ถ้าองค์กรไม่อนุญาตแชร์สาธารณะ ระบบจะโหลดรูปผ่านสคริปต์แทนโดยอัตโนมัติ)
- ข้อความที่ขึ้นต้นด้วย `= + - @` จะถูกกันไม่ให้กลายเป็นสูตรในชีต
- ระบบนี้เหมาะกับกลุ่มเพื่อน/ทีมเล็ก ถ้าต้องการสิทธิ์แยกรายคน ดูข้อ 11

## 11. ระบบที่แนะนำให้เพิ่ม

เรียงจากคุ้มค่าที่สุด — บอกได้เลยว่าอยากได้ข้อไหน

1. **QR พร้อมเพย์ต่อคน** — ใส่เบอร์/เลขพร้อมเพย์ครั้งเดียว ระบบสร้าง QR ตามยอดหารต่อคนให้สแกนจ่ายได้เลย
2. **แนบสลิปโอนเงิน** — ช่องชนิดใหม่ "รูปสลิป" ในหน้ารายชื่อ เก็บลงโฟลเดอร์ `สลิป/` ใน Drive พร้อมติ๊ก "ส่งเงินแล้ว" อัตโนมัติ
3. **แบ่งจ่ายไม่เท่ากัน** — เลือกว่าสินค้าแต่ละชิ้นเป็นของใครบ้าง แล้วคำนวณยอดของแต่ละคนแยกกัน
4. **หลายงาน/หลายทริป** — แยกรายการของกับรายชื่อเป็นชุด ๆ (เช่น "ทริปเชียงใหม่", "ปาร์ตี้ปีใหม่") เลือกสลับได้
5. **งบประมาณ** — ตั้งงบ แล้วแสดงแถบ "ใช้ไปแล้ว / เหลือ" และเตือนเมื่อเกินงบ
6. **แจ้งเตือนเข้า LINE กลุ่ม** ผ่าน LINE Messaging API เมื่อมีคนจ่ายเงินหรือเพิ่มของ (LINE Notify ปิดบริการไปแล้ว)
7. **ส่งออก PDF / พิมพ์ใบสรุป** สำหรับเก็บเป็นหลักฐาน
8. **ล็อกอินด้วยบัญชี Google** แทนรหัสผ่านร่วม — กำหนดได้ว่าใคร "ดูได้อย่างเดียว" หรือ "แก้ไขได้"
9. **สแกนบาร์โค้ด** ด้วยกล้องมือถือเพื่อเพิ่มสินค้าเร็วขึ้น
10. **ลากเพื่อจัดลำดับ** สินค้าและรายชื่อ
